Google Antigravity APT Repository

Official-grade automated Debian/Ubuntu packages for Google Antigravity 2.0 and Antigravity IDE

Quick Setup (Ubuntu / Debian)

Run the following commands to add the GPG key and APT repository to your system:

# 1. Install prerequisites
sudo apt-get update && sudo apt-get install -y ca-certificates curl gnupg

# 2. Add the repository GPG key
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://chmuri.github.io/antigravity-deb/public.key | sudo gpg --dearmor -o /etc/apt/keyrings/antigravity.gpg
sudo chmod a+r /etc/apt/keyrings/antigravity.gpg

# 3. Add the APT source (flat rolling repository)
echo "deb [signed-by=/etc/apt/keyrings/antigravity.gpg] https://github.com/chmuri/antigravity-deb/releases/download/apt ./" | sudo tee /etc/apt/sources.list.d/antigravity.list

# 4. Update and install Antigravity
sudo apt-get update
sudo apt-get install -y antigravity antigravity-ide

Available Packages

  • antigravity: Google Antigravity 2.0 desktop agent platform
  • antigravity-ide: Google Antigravity IDE development environment

Direct download links and release changelogs are available on GitHub Releases.
